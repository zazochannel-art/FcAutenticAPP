# Checklist testare

## Demo public

- Deschide `https://zazochannel-art.github.io/FcAutenticAPP/?v=super-admin`
- Login cu contul tău de super admin (credențialele nu se scriu în repository).
- Verifică Panou Super Admin.
- Verifică Admin.
- Verifică Echipă.
- Verifică Antrenamente.
- Verifică Meciuri.
- Verifică Finanțe.

## Roluri

- Super admin vede toate cluburile.
- Club owner vede clubul său.
- Coach vede grupele atribuite.
- Player vede doar datele sale.
- Parent vede doar copilul.

## Supabase

- Create club creează club real.
- Invite creează invitație.
- Accept invitation creează membership.
- Un club nu vede datele altui club.
